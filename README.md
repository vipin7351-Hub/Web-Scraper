# Churn Analysis
1. The Business Challenge
In the hyper-competitive OTT landscape (Netflix, Hotstar, Prime), retention is the only way to survive. You will 
act as a Data Analyst tasked with identifying high-risk subscribers using a multi-dimensional dataset (Customer 
demographics, Subscription tiers, and Support escalations).
2. Core Tech Stack
SQL & Python Integration (numpy, pandas, sqlite3, matplotlib, seaborn), Performance Engineering (data 
cleaning, feature engineering, analytics), Behavioral Visualization, Writing Actionable Insights
3. Project Milestones
• Relational Data Extraction: Connecting Python to SQL databases to pull multi-table datasets.
• Advanced Feature Engineering: Data imports, calculating tenure, churn rates, and customer aging. 
• Executive Reporting: Translating technical findings into billion-dollar business insights.
